## 🛠️ Hướng Dẫn Mở Tệp `.drawio`

1. **Cách 1 (Khuyên dùng - Nhanh nhất):**
   - Truy cập trang web: [https://app.diagrams.net](https://app.diagrams.net)
   - Chọn **Open Existing Diagram** $\rightarrow$ Chọn tệp `.drawio` trong thư mục này.
2. **Cách 2 (Mở qua phần mềm Draw.io Desktop):**
   - Tải Draw.io Desktop tại [https://www.drawio.com](https://www.drawio.com).
   - Double-click trực tiếp vào tệp `.drawio` để mở và chỉnh sửa.
3. **Cách 3 (Xem ảnh nhanh):**
   - Mở trực tiếp các tệp `.png` bằng Windows Photo Viewer.
