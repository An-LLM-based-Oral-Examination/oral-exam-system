MAIN WORKFLOWS
Flow 01 · Interactive Oral Practice (Interactive Practice)
Practice Session Setup · Multi-Modal Input (Voice or Text) · Upfront 2-Track Selection: [Per-Question] Instant Feedback & A2 Follow-up vs [Full-Session] Consecutive
01
STEP 1
Select Course & Topic
Student signs in, selects Course (PRN231, SWD), topic area, and difficulty level (Easy / Med / Hard).
DECISION
Select Upfront Mode
Choose evaluation policy: Per-question with A2 follow-up [Per-Question] or Full-session mock [Full-Session].
BRANCH 1 Per-Question Evaluation & A2 Follow-up Mode
Ideal for rapid reflex practice · Adaptive A2 recovery/deep-dive when 4.0 ≤ Score ≤ 8.0 (1-5 questions by Admin config)
STEP A1
Question Fetch & TTS
Backend fetches 1 question with 10.0 Rubric; Web Speech TTS reads question aloud via headphones.
STEP A2
Voice / Text Input & Buffer (Default 60s)
Choice of speaking via Mic (real-time STT) OR typing text directly; opens a countdown buffer (default 60s) to review terminology.
STEP A3
4-Tier Queue & LLM
Pending Save → BoundedChannel → Polly Retry → Gemini 1.5 Flash CoT evaluates 10.0 Rubric.
STEP A4
A2 Branch (4.0-8.0 pts)
Score 4.0-8.0: AI asks A2 deep-dive recovery question (1-5 questions by Admin config, default 2); <4.0 or >8.0: Open Scorecard.
STEP A5
Per-Question Scorecard
Modal renders rubric criteria scores, Web Speech reads feedback; Student proceeds to next question.
BRANCH 2 Full-Session Consecutive Mode & Score + Feedback
Simulates uninterrupted exam · No mid-session interruptions · Batch evaluation of all N questions
STEP B1
Load N-Question Set
Backend selects Bloom 1-6 matrix of N questions; initializes client-side continuous session state.
STEP B2
Answer N Questions (Voice / Text)
Student answers N questions sequentially via Mic or keyboard text; buffer per question (default 60s); cached locally without LLM calls.
STEP B3
Batch Final Submission
Upon finishing N questions, student clicks Submit; batch payload dispatched to 4-tier Zero Data Loss Queue.
STEP B4
Holistic AI Evaluation
Gemini 1.5 Flash CoT comprehensively reasons and grades all N questions against 10.0 Rubric in 1 request.
STEP B5
Scorecard & Feedback
Renders comprehensive scorecard breakdown across criteria alongside detailed AI feedback & recommendations.
